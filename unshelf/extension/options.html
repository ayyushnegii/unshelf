01

Transcription engine

Groq is faster and uses a free API key. Local Whisper is private and needs no key, but the first run downloads a model.

Free plan: about 2,000 requests/day and 8 hours of audio/day — plenty for 20–50 Reels. Get a key ↗

Only used when the local engine runs.

02

Instagram access

Public Reels usually work without login. If Instagram says the Reel is unavailable, let the bridge borrow cookies from the browser where you are logged in.

Cookies are read locally by yt-dlp and never sent anywhere except Instagram.

Privacy note Groq receives the Reel audio. Local Whisper keeps everything on this machine. Your API key is stored in Chrome's local extension storage, not synced.
03

Local bridge

The extension talks to a tiny helper on this computer. It does the Instagram download and, if chosen, the transcription.

Start it with unshelf\start-unshelf.bat.

Terminal
